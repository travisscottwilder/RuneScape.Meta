# NEW ACCOUNT SETTINGS
  - Open up settings and click into search
    - [ ] "report"           >> turn off "Player report options"
    - [ ] "run"              >> energy threshold to re-enable: set to "55"
    - [ ] "world switch"     >> uncheck world switcher conformation
    - [ ] "private"          >> uncheck "split friends private chat"
    - [ ] "transparent"      >> check transparent chat & side panel
    - [ ] "tips"             >> Turn off
  - Click "Interfaces" on the left side menu
    - [ ] "Game Client Layout" >> Resizable - Classic Layout
  - Click "Controls" on the left side menu
    - [ ] set up F1 keys
      - ESC = Combat Options
      - F1 = Inventory
      - F2 = Prayer
      - F3 = Magic Book
